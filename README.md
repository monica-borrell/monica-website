# Monica Borrell — Personal Website

A warm, approachable single-page personal brand website for Monica Borrell.

## Tech Stack

- Clean HTML, CSS, and minimal vanilla JavaScript
- No frameworks or build tools required
- Ready to deploy on [Netlify](https://www.netlify.com/) via GitHub

## Getting Started

1. Clone the repo
2. Open `index.html` in your browser — that's it!

## Photo

The hero photo is at `images/monica-photo.jpg`. It's displayed as a large rounded rectangle. To swap the photo, just replace this file — a landscape or portrait image works well.

## Deploy

This site is configured for Netlify:
- Connect the GitHub repo to Netlify
- No build command needed — the publish directory is the repo root (`.`)
- Deploys automatically on every push to `main`
